# Data Directory Guide (`data/README.md`)

This directory stores the raw ADNI4 source tables (`data/raw/`) and the processed cohorts generated by the pipeline (`data/processed/`).

> **Important (ADNI Data Use Agreement):** Raw ADNI4 CSV files and participant-level processed CSVs **are not included in this GitHub repository** because the [ADNI Data Use Agreement](https://adni.loni.usc.edu/wp-content/uploads/how_to_apply/ADNI_Data_Use_Agreement.pdf) prohibits redistributing participant-level ADNI data. Authorized researchers can obtain the exact source tables from the official ADNI portal below and recreate all processed datasets automatically.

---

## 1. Dataset Source and Download Instructions

* **Dataset Name:** Alzheimer's Disease Neuroimaging Initiative — Phase 4 (ADNI4)
* **Official Portal:** [https://adni.loni.usc.edu/](https://adni.loni.usc.edu/)
* **Data Access & Application:** [https://adni.loni.usc.edu/data-samples/adni-data/](https://adni.loni.usc.edu/data-samples/adni-data/)
* **Image & Data Archive (IDA):** [https://ida.loni.usc.edu/](https://ida.loni.usc.edu/)

### How to Obtain the Raw Files
1. Register for an account and submit an ADNI Data Use Application through the [LONI IDA portal](https://ida.loni.usc.edu/) (typically reviewed within 2 weeks).
2. After approval, log in to IDA → **Download** → **Study Data**.
3. Download the five CSV tables listed below (snapshot date used in this project: **06 Nov 2026**) and place them inside `data/raw/`.

---

## 2. Required Raw ADNI4 Files (`data/raw/`)

Place the following five files in `data/raw/`:

| File Name | ADNI Table / Domain | Dataset Type & Description | Role in This Project |
|---|---|---|---|
| `All_Subjects_DXSUM_06Nov2026.csv` | `DXSUM` (Clinical Diagnostic Summary) | Tabular longitudinal clinical diagnosis records (`PTID`, `VISCODE`, `EXAMDATE`, `DIAGNOSIS`: `1` = CN, `2` = MCI, `3` = Dementia). | Provides the clinical reference-standard diagnosis labels (`CN = 0`, `MCI = 1` for primary analyses; `MCI/Dementia = 1` for the all-pairs extension) and clinical diagnosis dates. |
| `All_Subjects_ECOG12PT_06Nov2026.csv` | `ECOG12PT` (Everyday Cognition 12-Item — Participant Self-Report) | Tabular questionnaire records containing 12 ordinal self-reported everyday-function items (`ECOGPT1`–`ECOGPT12`), collection date (`COLDATE`), and `VALIDITY` rating (`1` = Appeared Valid). Scale: `1` = Better/no change, `2` = Questionable/occasionally worse, `3` = Consistently a little worse, `4` = Consistently much worse, `9` = Don't know / N/A (recoded to `NaN`). | Supplies the 12 self-reported everyday cognition features (`ECOGPT3`–`ECOGPT12` retained in the reduced fusion model; `ECOGPT1` and `ECOGPT2` excluded). |
| `All_Subjects_PTDEMOG_06Nov2026.csv` | `PTDEMOG` (Participant Demographics) | Tabular participant demographic records including birth year (`PTDOBYY`), sex (`PTGENDER`: `1` = Male, `2` = Female), and years of education (`PTEDUCAT`). | Used in `Study 11B` (`src/04_evaluate_models_and_interpretation.ipynb`) to generate the participant demographics summary table (Publication Table 1) stratified by CN vs. MCI. |
| `DATADIC_06Nov2026.csv` | `DATADIC` (ADNI Data Dictionary) | Official ADNI metadata table defining table names (`TBLNAME`), CRF titles (`CRFNAME`), field names (`FLDNAME`), question text (`TEXT`), and valid value codes (`CODE`) across ADNI phases. | Used during preprocessing audits (`src/01_preprocessing.ipynb`) and manuscript verification to confirm exact `ECOG12PT` self-report item wording, response scales, and missing-value code `9`. |
| `RMT_STORYTELLER_06Nov2026.csv` | `STORYTELLER` (ADNI4 Remote Digital Storyteller Speech Assessment) | Tabular acoustic and linguistic speech-feature records (`STORY*` variables such as pause lengths, pause counts, idea density, word counts, and lexical ratios), assessment dates (`EXAMDATE_STORY`), and response completeness metadata from remote narrative recall tasks. | Supplies the 51 retained Storyteller speech predictors (after excluding `PLAYBACK_COUNT`, `GMATCH`, and `LANGUAGE` columns and zero-word/invalid records). |

## 4. Recreating All Processed Datasets

1. Place the five raw CSV files listed above into `data/raw/`.
2. Run preprocessing to generate the source cohorts (`dataset1_storyteller.csv`, `dataset2_ecog.csv`, and `dataset4_multimodal_cn_vs_noncn.csv`):
   ```bash
   jupyter nbconvert --to notebook --execute --inplace src/01_preprocessing.ipynb
   ```
3. Run Stage 3 (`Study 3`) to generate the single canonical 30-day matched primary cohort (`primary_multimodal_30day_cohort.csv`):
   ```bash
   jupyter nbconvert --to notebook --execute --inplace src/03_train_temporal_and_ablation.ipynb
   ```

## 5. Recommended `.gitignore` Entries

Add the following rules to your root `.gitignore` so participant-level ADNI data are never accidentally pushed to GitHub:

```gitignore
# ADNI raw and processed data (must not be redistributed)
data/raw/*.csv
data/processed/*.csv

# Participant-level prediction / SHAP files containing PTID
results/**/*participant_predictions*.csv
results/**/*participant_values*.csv
results/**/*heldout_*shap_values*.csv
results/**/*oof*.csv
```
